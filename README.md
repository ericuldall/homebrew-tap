# ericuldall/tap

Homebrew casks.

```sh
brew install --cask ericuldall/tap/weker
```

| Cask | What |
|---|---|
| `weker` | Weker for Mac, a menu bar time tracker that works out which project you're on. Test builds for teammates: macOS 26 on Apple silicon. |

Update with `brew upgrade --cask weker`. Weker test builds are signed but not notarized, so the cask removes the download quarantine flag after installing.
